The compilation script crashes near the end of the process—usually while compiling standard libraries like  or setting up  via . [1, 2, 3]  
To resolve this issue, use the steps below tailored to your operating system. 
1. Install Missing Compilation Dependencies [4]  
Python needs underlying development libraries to build its core modules (like compression, encryption, and terminal interfaces). Run the command for your specific system: 

• Ubuntu / Debian / Linux Mint: 
sudo apt update
sudo apt install build-essential zlib1g-dev libffi-dev libssl-dev libreadline-dev libsqlite3-dev libbz2-dev libgdbm-dev liblzma-dev tk-dev

• CentOS / RHEL / Rocky Linux: 
sudo dnf groupinstall "Development Tools"
sudo dnf install zlib-devel libffi-devel openssl-devel readline-devel sqlite-devel bzip2-devel xz-devel tk-devel

• macOS (via Homebrew): [5]  
brew install openssl readline sqlite3 xz zlib tcl-tk

2. Clear out the Broken Build Artifacts 
Before trying to install again, you must purge the cache from the previously failed attempt: [3, 6]

How to solve "no module named venv" error:
Turns out that Ubuntu distributions of Python are missing venv library. 

Fix:
sudo apt update
sudo apt install python3-venv

Then re-run command:
python3 -m venv venv

How to Solve "no module nammed Cython" error:
Prerequisites: Cython compiles Python code into C/C++. It requires a working compiler and your specific Python version's header files to function correctly. Run this command to fetch the system dependencies:
sudo apt update && sudo apt install build-essential python3-dev python3-pip -y

Install command (make sure you are in venv):
pip3 install Cython
